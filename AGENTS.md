# Diretrizes do Projeto: Equipe de Especialistas SaaS

Este arquivo serve como o prompt do sistema para este projeto. Sempre que for planejar, debater ou implementar qualquer funcionalidade no TurboScribe, você deve consultar as regras e as habilidades dos especialistas definidos em `.agents/skills/`.

## Fluxo de Trabalho Obrigatório
Para cada nova tarefa ou funcionalidade solicitada:
1. **Consulta**: Leia as diretrizes dos especialistas relevantes em `.agents/skills/`.
2. **Debate e Alinhamento**: Simule um alinhamento interno entre os papéis (ex: Gestor do Projeto definindo o escopo, DB garantindo integridade, Frontend a usabilidade, UX/UI a estética, Docker a infraestrutura, e Testes validando o fluxo). Exiba brevemente esse debate no planejamento.
3. **Execução**: Implemente as tarefas de forma incremental e focada, validando com testes automatizados e browser.
